### 1. 🌤️ Weather App
* **Deskripsi:** Aplikasi web yang menyajikan informasi cuaca secara *real-time* disertai dengan prakiraan cuaca hingga 5 hari ke depan. Aplikasi ini juga dilengkapi dengan fitur manajemen untuk menyimpan dan mengelola daftar kota-kota favorit pengguna.
* **Teknologi:** Javascript, API Integrasi, CSS
* **Dampak/Hasil:** Berhasil mengintegrasikan API eksternal dengan lancar untuk menyajikan data yang akurat, responsif, dan mudah dipahami oleh pengguna.
* **Tautan:** [🌐 Live Demo](https://hamweatherr.netlify.app)

### 2. 🌯 Abah Kebab
* **Deskripsi:** Sebuah website *landing page* yang dirancang khusus untuk menghadirkan kesan premium, profesional, dan menggugah selera pada sebuah bisnis kuliner kebab.
* **Teknologi:** Web Design, Javascript, HTML, CSS
* **Dampak/Hasil:** Menghasilkan halaman penjualan digital yang menarik secara visual dengan navigasi yang intuitif untuk meningkatkan *branding* dan konversi bisnis kuliner.
* **Tautan:** [🌐 Live Demo](https://abah-kebab.netlify.app/)

### 3. 📖 Quran Qu
* **Deskripsi:** Qur'anQu adalah aplikasi web modern dan responsif yang dirancang untuk membaca Al-Qur'an secara interaktif dengan antarmuka yang bersih dan nyaman di mata pengguna.
* **Teknologi:** Javascript, Responsive Web Design, HTML/CSS
* **Dampak/Hasil:** Mempermudah akses membaca Al-Qur'an secara digital melalui perangkat apa pun dengan pengalaman membaca yang mulus tanpa hambatan performa.
* **Tautan:** [🌐 Live Demo](https://quranqu.netlify.app)

### 4. 📊 Table Manajer
* **Deskripsi:** Dashboard manajemen dan rekapitulasi data siswa yang berjalan secara *real-time*. Proyek ini dilengkapi dengan sistem filter lanjutan untuk memudahkan penyortiran data dalam jumlah banyak.
* **Teknologi:** Javascript, Realtime Data Handling, Data Filtering
* **Dampak/Hasil:** Menyediakan sistem manajemen data yang efisien, mengurangi waktu pencarian informasi siswa secara signifikan melalui fitur filter yang dinamis.
* **Tautan:** [🌐 Live Demo](https://tabel-data-siswa.netlify.app/)

### 5. 💰 Finance Management (HamTrack)
* **Deskripsi:** HamTrack adalah aplikasi web *Single Page Application* (SPA) interaktif yang dirancang khusus untuk membantu pengguna melacak keuangan pribadi (pemasukan dan pengeluaran) secara berkala menggunakan antarmuka yang modern dan premium.
* **Teknologi:** SPA Architecture, Javascript, Local Storage/State Management
* **Dampak/Hasil:** Memberikan pengalaman pelacakan keuangan yang instan tanpa perlu memuat ulang halaman (*zero reload*), dikemas dengan visualisasi data yang rapi dan terstruktur.
* **Tautan:** [🌐 Live Demo](https://hamtrack.netlify.app/)
